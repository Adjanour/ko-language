Your First Ko Program

Lesson 001 · Mission

Ko is a functional language with linear types and an LLVM backend. This lesson gets you from zero to a running program in five minutes.

1. The smallest program

Every ko program needs a fn main entry point. Create a file called hello.ko:

fn main =
  println "Hello, world!"

Run it:

$ ko hello.ko
Hello, world!

That is it. No ko --run flag — just ko file.ko. The compiler compiles and runs in one shot.

Tip: ko --check file.ko parses and type-checks without running. Useful when you just want to verify syntax.

2. Basic types

Ko has integers, floats, strings, booleans, and characters:

fn main =
  inspect 42              # 42
  inspect 3.14            # 3.14
  inspect "hello"         # "hello"
  inspect True            # True
  inspect 'a'             # a

println prints with a newline. inspect prints the debug representation. print prints without a newline.

3. Let bindings

let binds a name to a value. Values are immutable:

fn main =
  let x = 10
  let y = x + 5
  inspect y   # 15
Gotcha: the value must be on the same line as =. Multi-line values do not parse: 
# THIS DOES NOT WORK:
let x =
  if 1 > 0 then 1
  else 2

# WORKS:
let x = if 1 > 0 then 1 else 2

4. Functions

Define functions with fn name params = body:

fn double x = x * 2
fn add a b = a + b

fn main =
  inspect (double 5)    # 10
  inspect (add 3 4)     # 7

No parentheses around function arguments when calling: add 3 4, not add(3, 4).

5. If expressions

if is an expression — it returns a value. else is optional:

fn main =
  let x = 42
  let msg = if x > 0 then "positive" else "non-positive"
  println msg

  # else is optional:
  if x > 0 then println "yes"

6. The pipe operator

Pipe |> passes the left side as the first argument to the right side:

fn main =
  # These are equivalent:
  inspect (Int.toString 5)
  5 |> Int.toString

  # Chained:
  5 |> Int.toString |> String.append "n="
  # = String.append (Int.toString 5) "n="
  # = "5n="
Common mistake: pipe passes as the FIRST argument, not the last. 10 |> sub 3 means sub 10 3 = 7, not sub 3 10 = -7.

7. Imports

The standard library lives in std/. Import with a std. prefix:

import std.List

fn main =
  let xs = Cons 1 (Cons 2 (Cons 3 Nil))
  inspect (List.length xs)   # 3

Selective imports bring names into scope:

import std.List.{map, filter}

fn main =
  let xs = Cons 1 (Cons 2 (Cons 3 Nil))
  inspect (map (\x -> x * 2) xs)   # [2, 4, 6]

Putting it together

A small program that reads a name and greets the user:

import std.io

fn greet name = "Hello, " + name + "!"

fn main =
  let name = IO.readLine "What is your name? "
  println (greet name)
$ ko greet.ko
What is your name? Alice
Hello, Alice!
