Modules and IO

Lesson 004 · Mission

Ko has a module system for organizing code and a set of IO builtins for talking to the outside world.

1. Standard library modules

The stdlib lives in std/. Import with the std. prefix:

import std.List
import std.String
import std.Int

Selective imports bring specific names into scope:

import std.List.{map, filter, foldl}
import std.String.{length, append}

Aliased imports give a short name:

import std.Int as I
# now use I.abs, I.min, I.max, ...

2. What each module provides

List (31 functions):

  • Construct: Cons, Nil
  • Access: head, tail, length, elem, find
  • Transform: map, filter, foldl, foldr, reverse, append
  • Query: any, all, sum, product, maximum, minimum
  • Slice: take, drop, zip, concat

String: length, append, charAt, substring, toInt, toIntOr, contains, split, trim, repeat, toLowerCase, toUpperCase

Int (builtins): Int.pow, Int.factorial, Int.abs, Int.min, Int.max, Int.gcd, Int.lcm, Int.isqrt

Int (with import): even, odd, mod, clamp, sign

Float: Float.sqrt, Float.sin, Float.cos, Float.floor, Float.ceil

3. IO builtins (global)

These are available everywhere without importing:

fn main =
  println "Hello"        # print + newline
  print "no newline"     # print without newline
  inspect 42              # debug representation
  eprintErr "warning"    # print to stderr

4. The io. module

For file and system IO, import std.io:

import std.io

fn main =
  # Check if a file exists
  let exists = IO.exists "myfile.ko"
  inspect exists   # True or False

  # Read a file
  match IO.readOrEmpty "myfile.ko"
    | Ok content => println content
    | Err _ => println "file not found"

IO functions:

  • IO.readLine prompt — read a line from stdin
  • IO.writeOrDie path content — write string to file (panics on error)
  • IO.readOrEmpty path — read file as Result
  • IO.exists path — check if file exists
  • IO.eprintErr msg — print to stderr

5. Two IO namespaces

Gotcha: there are two different IO things:
  • IO.* (uppercase) — global builtins, no import needed
  • io.* (lowercase) — imported from std.io
println is global. IO.readLine requires import std.io.

6. Local modules

Any .ko file in the same directory is a local module. Import by name without the std. prefix:

# math.ko
fn square x = x * x

# main.ko
import math

fn main =
  inspect (math.square 5)   # 25
