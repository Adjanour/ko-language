Types and Pattern Matching

Lesson 002 · Mission

Ko types are algebraic data types (ADTs): sums of constructors. Pattern matching destructures them. This lesson covers both.

1. Sum types

Define a type as a choice of constructors:

type Direction = North | South | East | West
type Maybe a = Just a | Nothing

Construct values by naming the constructor:

fn main =
  let d = North
  let x = Just 42
  let y = Nothing
  inspect d   # North
  inspect x   # Just(42)

2. Pattern matching

match destructures values. Each arm uses | prefix and =>:

fn turn_left dir =
  match dir
    | North => West
    | West => South
    | South => East
    | East => North

fn main =
  inspect (turn_left North)   # West

The wildcard _ matches anything:

fn is_just m =
  match m
    | Just _ => True
    | Nothing => False

3. Destructuring

Extract values from constructors:

fn describe m =
  match m
    | Just x => "Got: " + Int.toString x
    | Nothing => "Nothing"

fn main =
  inspect (describe (Just 42))   # "Got: 42"
  inspect (describe Nothing)     # "Nothing"

4. Recursive types

Types can reference themselves:

type List a = Cons a (List a) | Nil

fn length xs =
  match xs
    | Cons _ rest => 1 + length rest
    | Nil => 0

fn main =
  let xs = Cons 1 (Cons 2 (Cons 3 Nil))
  inspect (length xs)   # 3

5. Records

Records are named fields. Use RecordName { field = value } syntax:

type Person = Person { name : String, age : Int }

fn greet p =
  "Hello, " + p.name + "!"

fn main =
  let alice = Person { name = "Alice", age = 30 }
  println (greet alice)   # Hello, Alice!
  inspect alice.age       # 30

6. Tuples

Fixed-size anonymous collections:

fn main =
  let pair = (1, "hello")
  let triple = (1, 2, 3)
  inspect pair.0    # 1
  inspect triple.2  # 3
Gotcha: singleton tuples (42,) do not parse. Ko does not support them yet.

7. Built-in types

Primitives you get without defining:

  • Int — 64-bit signed integer
  • Float — 64-bit float
  • String — UTF-8 string
  • Bool — True or False
  • Char — single character ('a')

8. Type annotations

Annotate function parameters and return types:

fn add (a : Int) (b : Int) -> Int = a + b
fn double (x : Int) -> Int = x * 2
Gotcha: fn add a b : Int = does not parse. Use parentheses: fn add (a : Int) (b : Int) -> Int =.
