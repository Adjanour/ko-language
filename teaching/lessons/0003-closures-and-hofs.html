Closures and Higher-Order Functions

Lesson 003 · Mission

Functions are values in ko. You can pass them around, return them from other functions, and build them with closures.

1. Lambdas

Anonymous functions with \params -> body:

fn main =
  let double = \x -> x * 2
  let add = \a b -> a + b
  inspect (double 5)    # 10
  inspect (add 3 4)     # 7

2. Higher-order functions

Functions that take or return other functions:

fn apply_to_five f = f 5

fn main =
  let double = \x -> x * 2
  inspect (apply_to_five double)   # 10

3. Closures capture their environment

A closure remembers the variables where it was created:

fn make_adder n =
  \x -> x + n

fn main =
  let add5 = make_adder 5
  let add10 = make_adder 10
  inspect (add5 3)     # 8
  inspect (add10 3)    # 13

The \x -> x + n closure captures n from the surrounding scope. Each call to make_adder creates a new closure with its own n.

4. Stateful closures with ref

ref creates a mutable reference cell. Closures can capture and modify it:

fn main =
  let counter = ref 0
  let increment = \_ ->
    counter := !counter + 1
    !counter
  inspect (increment 0)   # 1
  inspect (increment 0)   # 2
  inspect (increment 0)   # 3

!counter reads the value. counter := writes it.

5. Map, filter, fold

The classic functional trio. Import from std/List:

import std.List.{map, filter, foldl}

fn main =
  let xs = Cons 1 (Cons 2 (Cons 3 (Cons 4 Nil)))
  let doubled = map (\x -> x * 2) xs
  let evens = filter (\x -> x % 2 == 0) xs
  let sum = foldl (\acc x -> acc + x) 0 xs
  inspect doubled   # [2, 4, 6, 8]
  inspect evens     # [2, 4]
  inspect sum       # 10

6. Currying

Every function in ko takes exactly one argument and returns one value. Multi-parameter functions are chains of one-argument functions:

fn add a b = a + b

fn main =
  # add 3 4 is actually (add 3) 4
  # add 3 returns a closure that adds 3 to anything
  let add3 = add 3
  inspect (add3 4)     # 7
  inspect (add3 10)    # 13

This is why map (\x -> x * 2) xs works: map takes one argument (the function) and returns a new function that takes the list.
